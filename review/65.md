### Core Middleware & Server Integration

#### `prash/middleware/security_headers.py`
> **Severity:** 🔴 Critical (Showstopper Bug)  
> **Issue:** Unconditional `Strict-Transport-Security` (HSTS) and `upgrade-insecure-requests` on plain HTTP.

```python
# CURRENT CODE:
DEFAULT_CONTENT_SECURITY_POLICY = (
    "default-src 'self'; "
    ...
    "connect-src 'self' http: https: ws: wss:; "
    "upgrade-insecure-requests"  # <--- DANGEROUS ON LOCAL DEV
)

SECURITY_HEADERS = {
    "X-Content-Type-Options": "nosniff",
    "X-Frame-Options": "DENY",
    "Strict-Transport-Security": "max-age=31536000; includeSubDomains",  # <--- DANGEROUS ON LOCAL DEV
    ...
}
```

- **Problem:** Lear is a local-first application. In development and desktop mode, `server.py` runs on plain HTTP (`http://127.0.0.1:8000` / `http://localhost:8000`) without TLS certificates.
  1. `upgrade-insecure-requests` instructs the browser/Webview to rewrite all subsequent requests and WebSockets (`http://localhost:8000/api/...`, `ws://127.0.0.1:8000/ws/events`) to `https://` and `wss://`. This causes immediate connection failures (`ERR_SSL_PROTOCOL_ERROR`) because Uvicorn is serving unencrypted HTTP.
  2. `Strict-Transport-Security` tells the browser to cache for 1 year that this host must *never* be accessed over HTTP. If a developer accesses `http://localhost:8000` in their browser, the browser permanently forces HTTPS for `localhost`, locking out local development.
- **Required Fix:** Make HSTS and `upgrade-insecure-requests` conditional on HTTPS or production mode (`ENVIRONMENT=production` and TLS active).

```python
# SUGGESTED REFACTOR:
import os

IS_PROD = os.getenv("ENVIRONMENT", "development").lower() == "production"

BASE_SECURITY_HEADERS = {
    "X-Content-Type-Options": "nosniff",
    "X-Frame-Options": "DENY",
    "Referrer-Policy": "strict-origin-when-cross-origin",
    "Permissions-Policy": "camera=(), microphone=(), geolocation=()",
}

DEFAULT_LOCAL_CSP = (
    "default-src 'self'; "
    "base-uri 'self'; "
    "object-src 'none'; "
    "frame-ancestors 'none'; "
    "form-action 'self'; "
    "script-src 'self' 'unsafe-inline'; "
    "style-src 'self' 'unsafe-inline'; "
    "img-src 'self' data: blob:; "
    "font-src 'self' data:; "
    "connect-src 'self' http: https: ws: wss:;"
)

def security_headers(is_https: bool = False) -> dict[str, str]:
    headers = dict(BASE_SECURITY_HEADERS)
    csp = os.getenv("LEAR_CSP")
    if not csp:
        csp = DEFAULT_LOCAL_CSP
        if IS_PROD or is_https:
            csp += " upgrade-insecure-requests;"
    headers["Content-Security-Policy"] = csp
    
    # Only emit HSTS when genuinely serving over HTTPS
    if IS_PROD or is_https:
        headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
        
    return headers
```

#### `.github/workflows/ci.yml`
> **Severity:** 🟡 Medium (Flaky Background Daemon)  
> **Issue:** Spawning a background uvicorn server in a shell step:
```yaml
shell: bash
run: |
  python -m uvicorn prash.server:app --host 127.0.0.1 --port 8000 --log-level warning &
  server_pid=$!
  trap 'kill $server_pid 2>/dev/null || true' EXIT
  ...
```
- **Feedback:** While the polling loop with `trap` works, spawning background background daemons in CI bash steps can occasionally hang or cause port collision issues on shared GitHub runners.
- **Recommendation:** `tests/test_security_hardening.py` already spins up FastAPI with `TestClient` and verifies headers across GET, error, HTML, and Streaming responses. If you keep the live server check, ensure the timeout is bounded and add an explicit `kill` fallback.
